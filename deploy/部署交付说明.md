# 云服务器部署 · 交付说明

**日期**：2026-08-03
**结论先行**：✅ 部署到腾讯云香港服务器是正确的选择（国外数据源刚需直连），部署包已全部就绪。

## 交付内容（deploy/ 目录）

| 文件 | 作用 |
|------|------|
| `docker-compose.yml` | 四容器编排：nginx + backend + postgres + redis |
| `Dockerfile.backend` | 后端镜像（Python 3.11 + FastAPI，含健康检查） |
| `nginx.conf` | 前端静态托管 + /api 反代，**SSE 流式关缓冲**（打字机效果关键） |
| `.env.example` | 环境变量模板（API Key / 数据库密码 / JWT 密钥 / 管理员密码） |
| `deploy.sh` | 一键部署脚本（校验 .env → 构建 → 启动 → 健康检查 → 输出访问地址） |
| `README.md` | 面向非技术用户的中文部署指南（服务器选型 + 步骤 + 排错） |
| `..\.dockerignore` | 构建上下文排除（密钥/日志/测试脚本不入镜像） |

## 代码改造（安全加固，向后兼容）

`backend/main.py`：JWT_SECRET、管理员账号密码原为**硬编码**，现支持从环境变量注入
（`JWT_SECRET` / `ADMIN_USERNAME` / `ADMIN_PASSWORD`）。
本地开发不设变量时行为完全不变，公网部署必须通过 .env 注入强密钥。
已通过语法校验。

## 部署三步走

1. 买一台腾讯云**香港**轻量应用服务器（2核4G，Ubuntu 22.04，放行 80/22 端口）
2. 上传项目 → 装 Docker → `cd deploy && cp .env.example .env` → 填入 4 个 API Key + 强密码
3. `bash deploy.sh` → 浏览器打开 `http://服务器IP` 登录验收

## 待办 / 风险提示

- ⚠️ 登录密码默认 `admin@2024`，部署前务必在 .env 修改（已写入部署文档）
